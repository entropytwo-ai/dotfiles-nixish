# dotfiles-nixish package list - the ONE list install.sh uses on every OS
# (Debian/Ubuntu, Fedora/RHEL, Arch, openSUSE, Alpine, NixOS) and that
# nix/packages.nix reads for the NixOS module and the flake.
#
# ADD YOUR OWN PACKAGES at the end, under [tools] - one per line.
#
# Line format:   name   [key=value ...]
#   name         the package name; also the command used to check whether
#                it is already installed
#   apt= dnf= yum= pacman= zypper= apk= nix=
#                package name(s) for that package manager when they differ
#                from "name" (yum falls back to dnf=):
#                  a,b   try a, then b (first that installs wins)
#                  a+b   install a and b together
#                  -     not needed / skip on that package manager
#   cmd=a,b      command(s) proving it is installed (any one is enough);
#                without cmd= a command named like "name" or the installed
#                package counts
#   path=a,b     file(s) proving it is installed (for packages without a command)
#
# Sections:
#   [prerequisites]  always, before the rest (download + git helpers)
#   [zsh]            only with --zsh
#   [ssh]            only for "Enable SSH" when no SSH server is installed
#   [sudo]           only for "Create a user" when sudo is missing
#   [locale]         only when the en_US.UTF-8 locale is missing
#   [tools]          the tool set - the "Dotfiles" menu item
# Unknown packages are skipped with a warning; the run goes on.
